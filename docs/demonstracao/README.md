# Fichas para demonstrar a digitalização

Arquivos com **dados 100% fictícios** para testar *Pacientes → Digitalizar ficha em papel*.

| Arquivo | Uso |
|---|---|
| `ficha-nasf-preenchida.pdf` | Ficha A.1 do NASF preenchida "à mão". Imprima e fotografe, ou envie o PDF direto. |
| `ficha-nasf-em-branco.pdf` | A mesma ficha em branco, para preencher à mão na hora (inclusive pela banca). |
| `ficha-simulada-foto-celular.jpg` | Foto simulada de celular (inclinada, com sombra) da ficha preenchida. |
